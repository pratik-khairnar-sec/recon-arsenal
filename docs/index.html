Modular Architecture

Engineered For High-Velocity Passive Intel

Six specialized reconnaissance engines operating in complete unison or standalone CLI modules.

Wayback CDX Streamer

Streams historical endpoint snapshots directly from the Internet Archive CDX API with HTTP status code filtering and sensitive extension detection.

AlienVault OTX Harvester

Pulls passive threat intelligence and observed historical URLs with automated pagination handling and multi-target rate management.

Passive Subdomain Resolution

Aggregates passive DNS records and DOM snapshot telemetries from urlscan.io and VirusTotal without pinging the victim servers.

IDN Homoglyph Defense

Permutates brand characters into Cyrillic and Greek homoglyphs, computing RFC-3492 Punycode for brand protection and phishing surface defense.

Surgical Google Dorking

Pre-built intelligence queries covering exposed administrative portals, database backups, private keys, environment files, and cloud storage.

Telegram Alert Dispatcher

Zero external dependencies. Uses standard Python urllib to push instant HTML-formatted alerts directly to Telegram channels and private chats.

Zero Installation Friction

Quick Setup & Execution

ReconArsenal runs entirely on Python standard library without requiring pip dependencies.

1. Clone the repository:

git clone https://github.com/pratik-khairnar-sec/recon-arsenal.git && cd recon-arsenal

2. (Optional) Configure Telegram Bot Alerts:

python telegram_notify.py --setup

3. Launch Interactive Terminal UI or run Full Scan:

python arsenal.py -d target.com --all --notify -o results.txt
